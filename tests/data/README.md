# The committed MusicXML corpus

Every file here except `Trouble_in_Mind_Blues.musicxml` is generated by
`tests/fixture_scores.py`. The generated scores are original material: new
melodies, no lyrics, and only the harmonic cells the tests name. The chord
progressions are not the protected part of a lead sheet, and the melodic lines
are not the retired tunes.

`Trouble_in_Mind_Blues.musicxml` is retained because it is the only committed
notation-program export that carries cross-barline ties on a 4/4 blues, which is
the case `tests/test_headxml.py::TestAHeldNoteIsOneNoteAcrossABarline` pins.
It is not generated, and `tests/test_fixture_corpus.py` names it as the one
deliberate exception.

## What each generated file is for

| file | features |
|---|---|
| `synthetic_common_8.musicxml` | 4/4, a repeated-note bar, a melody-less last bar, a `C13`/`Eb5` window case |
| `synthetic_cut_time.mxl` | 2/2, a one-quarter pickup rest, a cross-barline tie, a melody-less downbeat |
| `synthetic_pickup_common.musicxml` | 4/4, an incomplete first bar with no `light-light` |
| `synthetic_pickup_cut.musicxml` | 2/2, an incomplete first bar closed by `light-light` |
| `synthetic_repeat_slash.musicxml` | 2/2, a repeat with two endings, a slash chord, a `<degree>` alteration |
| `synthetic_tab_export.musicxml` | a notation part and a TAB part, chord groups, triplets |
| `synthetic_triplets.mxl` | 2/2 in 10080 divisions, triplets, a repeat, a gcd-1 onset |
| `synthetic_waltz.musicxml` | 3/4, a repeat with two endings, eighths |
| `synthetic_five_four.musicxml` | 5/4, a `3+2` direction, the score's own asymmetric grouping |
| `synthetic_seven_four.musicxml` | 7/4, eighths beamed 2+2+3 |
| `synthetic_twelve_eight.musicxml` | 12/8, eighths beamed 4+4+4 rather than the automatic threes |
| `synthetic_chords_only.musicxml` | four bars, six `<harmony>` symbols, no pitched notes |

## Regenerating

```bash
.venv/bin/python tests/fixture_scores.py
.venv/bin/python tests/fixture_scores.py --check   # no write; fails on a drift
```

`tests/test_fixture_corpus.py` runs the same comparison as part of `make check`,
and refuses any retired filename. It also checks the two things a notation
program needs before it will open a score cleanly: every note and rest states the
`<type>` its `<duration>` corresponds to, and every non-pickup measure adds up to
its time signature. `music21` sums durations and tolerates a missing type, so a
round trip through the importer alone cannot catch either omission.

## History

The files this corpus replaced are recorded in git history and, where the
reasoning matters, in `docs/history/`. Do not restore one by name: a filename in
`RETIRED` is a signal that the file was a copyrighted transcription, not a
fixture.
